    How the engine adapts

    A small Mamdani fuzzy inference system scores every organelle on five linguistic variables, fires a rule base, then defuzzifies the result into a concrete plan.

    1 · It reads the last runs

    For each structure the engine tracks mastery, how consistent you are, how fast you answer and how long ago you last saw it.

    2 · Rules fire

    "Mastery is poor" plus "answers are erratic" lights up the intense reinforcement set. Confident, recent answers light up the gentle set instead.

    3 · The board follows

    Defuzzified demand decides which organelles appear, which get a second pair, and whether the question is a warm-up, core or challenge.

    4 · Nothing is lost

    Mastery, scores, streaks and the run in progress all live in local storage, so the engine keeps learning between sessions.
